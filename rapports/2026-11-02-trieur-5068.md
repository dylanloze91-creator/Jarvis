## En clair, pour thedexios

Jarvis peut maintenant préparer un **petit modèle rien qu'à choisir l'équipe** (conversation, PC, fichiers, etc.), à la place du gros cerveau 7B. Tout est **prêt dans le code**, mais **rien ne change** tant que vous n'avez pas : trié vos phrases, généré le cahier, entraîné sur votre RTX 2060, exporté `jarvis-trieur`, et choisi ce modèle dans Réglages → Chef d'orchestre → **Trieur**.

Le guide pas à pas est dans `training/TRIEUR.md`.

**À tester vous-même sur Windows :**

1. Extraire puis ouvrir la page de tri : une phrase doit s'enregistrer dans `examen.jsonl` avec un bouton équipe.

3. Retirer le trieur dans les réglages : le même type de demande doit repasser par le **cerveau** (pastille « choisi par le cerveau ») ou le chat d'avant si l'orchestre est coupé.
