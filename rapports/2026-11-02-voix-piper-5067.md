## En clair, pour thedexios

Jarvis peut maintenant parler avec une **voix française locale Piper** : gratuite, sans Internet, une fois les fichiers installés. Ce n’est **pas** activé tout seul : le réglage par défaut reste la voix Windows du navigateur. Tu choisis **« Piper (voix locale gratuite, sans Internet) »** dans Réglages → Voix, tu peux **Écouter** une phrase d’exemple, et tu picks une voix (Siwis, Jessica ou Pierre). La même voix sert la fenêtre, l’enceinte (si tu as choisi Piper) et l’iPhone (le PC envoie le son en WAV).

**Ce que tu dois tester sur ton PC Windows** (voir RAPPORT DE VÉRIFICATION) : choisir Piper, écouter l’exemple, poser une question vocale, tester l’enceinte et le téléphone si tu les utilises.

## Livré

- Moteur Piper en processus séparé (`apps/desktop/src/main/piper/`), texte sur stdin, modèles ONNX dans `voice-assets/piper/` via `setup:voice` / `setup-piper.mjs`, empreintes SHA-256.
- Registre TTS `local-piper` + trois voix françaises (licences OK pour l’installateur).
- Fenêtre : lecture WAV, enchaînement phrase par phrase si le texte est long ou si la synthèse est lente.
- Enceinte : Piper en priorité si réglage Piper, repli voix Windows.
- Téléphone : `/api/me` → `voice: "piper"` ; `POST /api/speak` (jeton, ≤ 1 500 caractères, texte nettoyé comme l’enceinte).
- Tests Vitest avec moteur simulé ; Piper réel sur Linux : ~3,1 s pour ~400 caractères (Siwis, CPU seul).
- Taille ajoutée à l’installateur (mesurée sur cette VM après téléchargement) : **~211 Mo** (`bin/` ~52 Mo, `models/` ~134 Mo, cache d’archives compris).

**À tester toi-même sur Windows :**

1. Réglages → Voix → moteur **Piper** → **Écouter** : tu dois entendre la phrase d’exemple sans Internet.
2. Active la réponse vocale, demande à voix haute « Jarvis, quelle heure est-il ? » : réponse lue avec la voix Piper choisie ; **Couper** pendant la réponse doit arrêter net.
3. Si tu utilises une enceinte ou l’iPhone avec Piper sélectionné : une réponse courte doit sortir avec la même voix (enceinte en WAV 16 kHz ; iPhone via lecture du WAV du PC, pas la voix Siri).
