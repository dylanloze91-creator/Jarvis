À écarter :

1. les lignes avec `isSidechain: true` et tout fichier d'un sous-dossier `subagents` : ce sont les consignes de Claude à ses sous-agents ;
2. les résumés de reprise : `isCompactSummary: true`, ou un texte qui commence par « This session is being continued from a previous conversation » ;
3. les blocs ajoutés par l'outil : un texte qui commence par `<system-reminder>`, `<command-name>`, `<command-message>`, `<local-command-stdout>`, `<local-command-stderr>`, `<task-notification>`, ou par « Caveat: The messages below were generated by the user while running local commands » ; et les morceaux `<system-reminder>…</system-reminder>` à l'intérieur d'un message gardé ;
4. « [Request interrupted by user] » et « [Request interrupted by user for tool use] » : à compter comme une interruption (un raté possible), jamais comme une demande.
