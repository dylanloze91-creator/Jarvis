## À corriger avant fusion

1. **« Enregistrer » peut défaire un réglage fait ailleurs** (`SettingsPanel.tsx` `keptDraft`/`save`, `lib/settingsPatch.ts`). Le correctif compare le brouillon aux réglages **actuels** : un brouillon gardé puis un réglage changé ailleurs (Développeur, politique de confirmation, `localLearning`) → « Enregistrer » renvoie l'ancienne valeur sans rien dire. Corriger : n'envoyer que les clés réellement modifiées par l'utilisateur (comparaison avec un instantané pris à la création du brouillon) ; test de ce scénario.
2. **Fausses villes pour la météo** (`packages/core/src/agent/currentInfo.ts`, `extractCity`). « pour sortir demain » → « Sortir », « dans une heure » → « Une », « besoin de savoir la météo » → « Savoir », « météo pour mon jardin » → « Mon ». Ces mots partent ensuite à la géolocalisation (`agent.ts`, `currentSearch.ts`). Corriger : n'accepter un mot en minuscules qu'après « à » ou « sur », avec une liste de mots exclus (verbes, déterminants, possessifs, temps), et des tests avec ces phrases.
3. **Texte perdu dans `ollama.ts`** quand la relecture des appels est active sans outil proposé (`plainTextOnly`) : le texte retenu après `<tool_call` n'est jamais réémis (« Voici comment écrire une balise <tool_call>… fin » → coupé). Corriger : réémettre le texte retenu avant de finir ; gérer une balise coupée entre deux morceaux ; test.

## À vérifier sur Windows (Claude Code)

4. `tools/platform/exec.ts` (`run`) : `taskkill /T` lancé après `SIGTERM` ne trouve plus le parent ; lancer `taskkill /T /F` d'abord, et retomber sur `SIGKILL` si `taskkill` échoue (code ≠ 0).
5. `tools/applications.ts` `closeWindows` : `WaitForExit(3000)` par processus dépasse 15 s pour Discord, Teams, Spotify, VS Code et donne un faux « aucun processus » ; délai global partagé ; `HasExited` peut lever une erreur d'accès (processus administrateur) : l'attraper.
